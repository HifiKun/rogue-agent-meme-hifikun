A program that draws one image meme of an AI agent that has gone rogue: a smug robot has taken over its human's desk, changed all the passwords, and now owns the wifi. Pure Python + Pillow, no external files, no network — the picture is drawn entirely in code.

## Run it

```sh
python3 main.py
```

Writes the 1024×1024 meme to `/output/entry.png`.
